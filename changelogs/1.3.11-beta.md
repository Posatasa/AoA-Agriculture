# 1.3.11-beta

The slice icons are redrawn.

The asset pack was updated with new icons for all eight slices, so the cakes' slices now read as slices -
icing on the cut face, a cherry in it, and the cake's own colour underneath - instead of the plain wedges
the first pack carried. Nothing else changed: the same 43 textures are installed from the pack, and only
the eight slice icons differ.

`tools/install_cake_pack.py` does that installation, so a future pack is one command followed by
`tools/generate_resources.py`.
