# 1.2.22-beta

Three fixes to the candied water bottle.

**A glass bottle no longer produces a water bottle.** The fill handler asked "is this a source block"
before acting - and AoA builds its fluid blocks from the *flowing* fluid, so their fluid state reports
itself as flowing even for a full block. The handler stepped aside, vanilla's bottle took over, and
vanilla's bottle fills from any block that will hand a fluid over, always giving a water bottle. The
gate is gone; the fluid is identified by which fluid it is, and taking it is the real test, since it
only succeeds on a full block.

**The bottle is no longer pink.** The icon was the honey bottle recoloured whole, glass included. It
is now drawn the way vanilla draws a potion - the glass bottle, with the potion's liquid layer tinted
AoA's candied colour inside it - so the glass stays glass and only the drink is pink.

**It can be drunk at any hunger.** It was gated like a honey bottle, which meant that with a full bar
nothing happened at all, which reads as a broken item. Six hunger and a little saturation when
hungry; always drinkable otherwise.

The build now refuses a fill handler that gates on `FluidState.isSource`, because that is exactly the
shape of the bug that shipped: it looks careful and it silently disables the item. I checked the
check bites by putting the gate back and watching the build fail.
