# 1.2.26-beta

The Dark family now follows the same naming as every other one.

`dark_bucket` is the **empty** bucket (暗黑桶) and `lava_dark_bucket` is the endless lava one
(暗黑熔岩桶), the same way Limonite, Rosite, Shyre, Lunar, Emberstone and Blazium are named. The
previous version had it backwards, with the endless one holding the plain name.

The divine station upgrade makes the empty bucket and **only accepts the empty bucket**: a dark
upgrade kit used on an empty Blazium bucket gives an empty Dark bucket. A filled Blazium tank cannot
be traded in, so the recipe cannot be used to conjure an endless lava source out of the tank you were
going to empty anyway.

The Dark bucket's colour now comes from AoA's **darkly powder** - the black the upgrade kit itself is
made from - rather than a darkened blazium red, so it reads as black instead of very dark brown.

Also: the generator now clears the directories it generates in full before writing them. Renaming an
item previously left its old model behind, and a model with no name is an item that shows up unnamed
and without an icon - which the build caught, but only after it had been written.
