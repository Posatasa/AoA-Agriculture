# 1.2.21-beta

A bottle of candied water, and the main class finally has the mod's name.

**`aoaagriculture:candied_water_bottle`** - right-click AoA's candied water with a vanilla glass bottle
to fill one. Drinking it works like vanilla's honey bottle: six hunger, the honey bottle's 40-tick
drink and animation, and the glass bottle back afterwards (dropped on the ground if there is no room).
Crafting it gives three sugar and returns the bottle, which is how vanilla turns a honey bottle into
sugar, so a candied water pool is now a renewable sugar source much as a bee farm is.

It is drawn from vanilla's honey bottle recoloured to AoA's candied water colour - only the colour is
taken from AoA, never a pixel, the same rule the buckets follow.

Filling is done with Forge's right-click event rather than by patching vanilla's bottle. Vanilla's
bottle only fills from `#forge:water`, so it looked at candied water and did nothing; this only ever
acts on AoA's fluid, and leaves vanilla's water behaviour untouched. The fluid is matched as a
source, since AoA's fluid blocks report the flowing fluid.

The main class is now `AoAAgriculture` instead of `AddonFarmland` - it was the last thing still
carrying the name from before the rename. The mod id, the mod name and the jar were already renamed,
so nothing else changes.

The build now checks that the bottle has a model, a texture and a name, that it overrides the four
methods a drink needs, and that it sets a crafting remainder - losing that last one would turn "sugar
from sugar water" into a recipe that quietly eats the glass bottle. I checked that the check bites by
removing the crafting remainder and watching the build fail.
